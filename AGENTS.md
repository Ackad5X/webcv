# AGENTS.md

Context and rules for agents (Claude Code and similar) working in this repository. Single-developer portfolio project, no team behind it — these rules exist to keep the site simple, deployable, and free of surprise dependencies, not as a large-team process.

The single most important rule: **this site must always remain deployable to GitHub Pages**. See `.agents/rules/deployment.md` before touching routing, build, or assets.
