# Code language

All source code must be in **English**: variable/function/component names, comments, commit messages, and any configuration or technical documentation (including this `AGENTS.md` itself and its rule files).

**Exception**: the bilingual content shown on the site through the language switcher (the `es` fields of the `L` type in `src/content/site.ts` and other Spanish text shown when clicking the en/es switch). That Spanish is site content, not code — leave it as is.

Don't mix the two: don't add Spanish comments to the code, and don't name identifiers in Spanish, even though nearby content (`content/*.ts`) has Spanish strings as data.
