# Alejandro Castaño — Security Architect WebCV & Portfolio

An interactive, bilingual WebCV and technical portfolio for **Alejandro Castaño**, a Multi-Cloud Security Architect specializing in **SSE / SASE** and **Zero Trust** architectures (Zscaler, Netskope, Palo Alto Networks).

Built with **TanStack Start**, **React 19**, **Tailwind CSS v4**, and **shadcn/ui**.

---

## About the Project

This project is a dedicated WebCV designed to present enterprise security engineering experience, production case studies, industry credentials, and security automation tooling in a clean, interactive format.

### Key Highlights

- **Bilingual Experience (EN / ES)**: Client-side language switching between English and Spanish, with persistent preference storage and zero layout flicker.
- **Enterprise Case Studies**: Detailed breakdowns of architectural deliveries across regulated sectors (Banking, Energy, Transport, Public Sector, Healthcare) — detailing context, challenge, technical approach, stack, and outcomes.
- **15+ Vendor Certifications**: Interactive catalog of industry credentials across Zscaler, Netskope, and Palo Alto Networks, with verification links and official badges.
- **AI & Security Automation**: Showcase of custom security tooling and AI-assisted workflows built for security operations and architecture validation.
- **Downloadable Profile**: Direct access to the official CV document.
- **Modern, Accessible Interface**: Single-page architecture crafted with Tailwind CSS v4, Radix UI primitives, and custom dark theme aesthetics.
